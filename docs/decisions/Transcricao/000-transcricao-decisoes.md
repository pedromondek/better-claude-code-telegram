# Transcrição — Decisões

## Resumo

Fonte **canônica** das decisões da transcrição dos áudios que o usuário manda ao bot: onde ela roda, o que fica guardado e quais versões o setup instala. Cada arquivo descreve a decisão **no estado atual** — o que foi decidido, por quê e o que foi descartado — sem histórico cronológico.

Convenção: **um arquivo por decisão** (`NNN-slug.md`), no formato **Decisão · Porquê · Descartado**. Este arquivo (`000`) é o índice.
