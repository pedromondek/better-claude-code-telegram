# Setup — Decisões

## Resumo

Fonte **canônica** das decisões do setup no terminal: como o `bcct setup` pergunta, volta e mostra as opções. Cada arquivo descreve a decisão **no estado atual** — o que foi decidido, por quê e o que foi descartado — sem histórico cronológico.

Convenção: **um arquivo por decisão** (`NNN-slug.md`), no formato **Decisão · Porquê · Descartado**. Este arquivo (`000`) é o índice.
