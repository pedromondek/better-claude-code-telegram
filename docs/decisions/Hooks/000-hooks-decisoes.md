# Hooks — Decisões

## Resumo

Fonte **canônica** das decisões do plugin `telegram-hooks`: como as instâncias do Claude Code da máquina chegam ao Telegram e como a resposta volta ao terminal. Cada arquivo descreve a decisão **no estado atual** — o que foi decidido, por quê e o que foi descartado — sem histórico cronológico.

Convenção: **um arquivo por decisão** (`NNN-slug.md`), no formato **Decisão · Porquê · Descartado**. Este arquivo (`000`) é o índice.
