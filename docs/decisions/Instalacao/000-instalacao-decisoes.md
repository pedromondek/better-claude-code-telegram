# Instalação — Decisões

## Resumo

Fonte **canônica** das decisões sobre como o usuário instala, atualiza e remove o projeto: as entradas, onde fica o binário, os caminhos que a statusline e o shell usam e o que vem do marketplace. Cada arquivo descreve a decisão **no estado atual** — o que foi decidido, por quê e o que foi descartado — sem histórico cronológico.

Convenção: **um arquivo por decisão** (`NNN-slug.md`), no formato **Decisão · Porquê · Descartado**. Este arquivo (`000`) é o índice.
