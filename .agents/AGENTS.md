# Shared Claude Code guidance

The canonical project instructions live in [`.claude/CLAUDE.md`](../.claude/CLAUDE.md). Read it before making changes, then read the applicable files under [`.claude/rules/`](../.claude/rules/) when that folder exists on your machine.

For persistent project feedback and decisions, look for the per-user Claude project-memory index at `~/.claude/projects/<encoded-current-repository-path>/memory/MEMORY.md`, then open the entries relevant to the task. The encoded directory is the Claude Code representation of the current repository's absolute path. If it does not exist on the current machine, continue without it; never add a user-specific path or memory content to the repository.
