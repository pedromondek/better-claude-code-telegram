# /bcct:setup

Do not run anything. Tell the user, in their language:

- The full setup runs in their own terminal, because it asks the bot token hidden and pairs their Telegram account: `npx better-claude-code-telegram`. Running it again keeps what is already done.
- Only the plugins and the shell line: `npx better-claude-code-telegram plugin`, also in their terminal.
- Everything else can be changed from here: `/bcct:language`, `/bcct:delay`, `/bcct:quiet-hours`, `/bcct:transcription`, `/bcct:statusline`; and `/bcct:health` checks it all.
