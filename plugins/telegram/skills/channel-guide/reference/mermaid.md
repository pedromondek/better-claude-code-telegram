# Flows and drawings on Telegram

When a flow is finished, or something is easier to understand drawn:

1. Write it as a mermaid file in the scratchpad, for example `flow.mmd`.
2. Render it with the mermaid renderer named in SKILL.md, passing that file. It prints the path of the PNG.
3. Send the PNG with reply(files: [path]) and a short caption.
